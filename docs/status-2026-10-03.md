# Status — 2026-10-03

## What was built

### Branch `concept-map-phase1`

Four engine fixes plus a scorecard fix:

1. **Physical-act verb routing** — added 8 new trigger groups to `applyCriminalExpansions` (homicide, assault, vehicular, criminal damage, extortion, unlawful confinement, receiving stolen property, criminal possession). Physical-act descriptions now enter the concept-map path instead of the text-search path.
2. **Empty-terms gate** — when `terms=[]` and no keywords, return `noConfidentMatch=true` immediately. Fixes T24 and similar no-anchor cases.
3. **Word-form tolerance** — upgraded `windowContainsAll` to `tokenMatchesTriggerOrPrefix`; the function now matches feminine ة forms, definite ال prefix, attached و/ف/ب/ل/ك prefixes, forward-prefix suffixes (up to +3 chars), and reverse-prefix roots (up to +3 chars).
4. **CONCEPT_TO_ARTICLES expansion** — added Arts. 142, 164, 176, 180, 181, 182 (unlawful confinement, extortion, criminal possession, receiving stolen, criminal damage, plus assault range).
5. **Scorecard runner fix** — `must_not` at rank-1 always scores 0, even if the same article appears in `also_acceptable`. Removed `&& !r1InAlso`. Corrected B1-008 from 0.5 to 0.

Batch-number argument added to `run-batch1.ts` (`process.argv[3]`, 1-based).

### Branch `semantic-layer` (from `concept-map-phase1`)

LLM post-deterministic veto — `lib/case-mapper/llm-classifier.ts` (new) and changes to `lib/case-mapper/analyze.ts`:

- Claude Haiku 4.5 called on every `analyzeCase` request, **including when word lists fired** (post-deterministic veto).
- Returns one concept from a closed list matching `CONCEPT_TO_ARTICLES` keys exactly, or `"civil"`, or `"abstain"`. Article numbers never come from the LLM.
- On `abstain` → immediate `noConfidentMatch: true`, overrides any word-list result.
- On `civil` → suppresses criminal path; civil text search runs as before.
- On criminal concept → LLM concept replaces word-list concepts; `anyFired = true`.
- `ANTHROPIC_API_KEY` read from `process.env`; facts text never logged.

Two prompt iterations committed:
- **Prompt v1** (strict element-checklist): abstain if any offence element absent from the facts. Tested — caused over-abstention (see scores below).
- **Prompt v2** (context-inference): abstain only when (a) cannot determine whether the act is criminal at all, or (b) facts irreconcilably fit two materially different offences. Explicit rules: do not abstain because facts are brief; do not abstain because an element is implied rather than stated. **Not yet tested** — key expired before second run.
